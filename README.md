# Installation
1) In der Datei `ProjectIgnis/config/configs.json` wird die Option `has_core` vom Repository `Project Ignis updates` auf `false` gestellt.
2) Lade die Datei `ocgcore.dll` vom aktuellsten Release herunter und platziere sie im Ordner `ProjectIgnis`.
3) Missbrauche die neuen Features :3
